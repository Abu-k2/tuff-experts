# Tuff Experts

Official website for Tuff Experts — professional carpet laying, tuff field installation, wall & floor tiling, wooden & laminate flooring, and painting services in Nairobi. Built with React, Vite, TypeScript and Tailwind CSS.

Live site: https://general-carpets-experts.vercel.app

## Run Locally

**Prerequisites:**  Node.js

1. Install dependencies:
   `npm install`
2. Run the app:
   `npm run dev`

## Build for Production

`npm run build` — output is generated in `dist/` and deploys to Vercel automatically.
